# AI Safety Index

A public, buildless static portal connecting AI safety papers, data/tasks, benchmarks, published results and curated research highlights. Canonical hosting is https://gabrygao.github.io/ai-safety-index/ in GabryGao/GabryGao.github.io, under ai-safety-index/. Preserve other repository files during publication.

Six overlapping research topics connect shared resources: data/privacy, foundation models, agents/software, physical AI, human/societal safety and AI+X/science. Homepage highlights are manually curated, independent from topic pages, and tagged by direction. Do not add paid scraping, login or new backend services without a request.

The library contains 490 bibliography records, including 487 selected from OpenTAI's public GitHub catalog, with retained source attribution. Inclusion does not establish full-text review or experimental reproduction. Historical HELM results retain model versions and evaluation conditions and are not a current leaderboard.

Chinese, English, Japanese and German are available via the header. Language changes must not navigate or re-render the page. Preserve current route, filters, page, drafts and comparison selections. Scientific titles, authors, URLs and record identifiers remain original. `locale.js` supplies offline UI translations and multilingual topic/category search.

The user now requests a Madeo-inspired block layout instead of long linear lists. Keep the white page background and local editorial fonts. See DESIGN.md and the final stylesheet portal-grid.css. Maintain existing original-source links and all browsing interactions.
